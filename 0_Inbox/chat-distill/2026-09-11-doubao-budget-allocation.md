# Distilled: PC Budget Allocation Framework

## Background

Asked AI to structure how I allocate a PC build budget across components, based on the configs I had been sending to customers.

## Conclusion/Method

- **CPU + GPU take 50-60% of the total budget** — they define the performance class of the machine.
- **Motherboard + RAM + storage = 20-25%** — buy for the platform, not for the brand; never over-spend on the board.
- **PSU is the one part not to cut** — an unstable PSU silently degrades everything else; reserve ~10%.
- **Case + cooling = the remaining ~10-15%**, and it is the only place where looks justify spending.

## Quotes

- "A customer remembers the CPU model, but an unstable power supply is what makes them return it."

## My notes

This matches my sales experience; formalize it as a framework entry and point customers to it instead of re-explaining every time.
